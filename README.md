# String Utils

A tiny collection of string helper functions in Python.

## Functions

- `is_palindrome(text)` — checks if a string is a palindrome (ignoring case and spaces).
- `reverse_words(text)` — reverses the order of words in a string.
- `truncate(text, max_length)` — truncates a string to a max length, adding `...` if needed.
